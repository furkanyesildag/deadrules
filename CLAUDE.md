# deadrules

A CLI that measures which rules in an agent instruction file actually change
what the agent does.

## Build and test

- Run `npm test` before claiming anything works. It builds first, so a type
  error fails the run.
- Never edit files under `dist/` — they are generated by `tsc`.
- Keep the package dependency-free at runtime. Dev dependencies are fine.

## Style

- Write comments that explain why a decision was made, not what the line does.
- Prefer explicit narrow types over `any`, and keep `noUncheckedIndexedAccess`
  satisfied rather than reaching for non-null assertions.
- Name things the way the surrounding file already names them.

## Statistics

- Never report an effect without the test that justifies it. Anything derived
  from fewer than four trials per arm cannot reach significance and must be
  reported as inconclusive.
- Say "no evidence of an effect", never "no effect".
- Correct for multiple comparisons whenever more than one rule is tested.

## Agent runs

- Every agent invocation happens in a throwaway git worktree, never in the
  user's checkout.
- Respect the budget caps before spending, not after.
